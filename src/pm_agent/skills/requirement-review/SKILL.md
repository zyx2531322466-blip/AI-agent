# 逐条评审规范

- 一次只看一条需求，别把整份规范拿来泛泛而谈。
- 对每条问四件事：能不能验收（做完怎么证明）、范围清不清（含不含"不做"）、
  有没有和别的条目重叠、是不是推测（使用者真说过吗）。
- 挑出问题时给出具体改法，而不是"这条不清楚"。
- 分不清该问谁的，归到"需要人工裁决"，不要替使用者决定。
- 评完给一份汇总：几条可直接改、几条要问人、几条建议删。
