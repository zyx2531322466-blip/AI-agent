inputs: 任务状态与更新时间、风险视图、最近的交接记录
outputs: 一份结论在前的汇报：完成了什么、卡在哪、有什么风险、需要谁做什么
why: 上级的时间有限，想看的是结论和风险，不是逐条流水。但结论必须能追溯到记录，否则汇报就成了表态。

# 写一份周报

- 结论放在最前面：一句话说清"这周到哪了"。
- 分四类：已完成 / 进行中 / 阻塞 / 风险；没有的那类如实写"无"。
- 每条都带来源（哪条任务、哪次变更）——没有来源的成果别写。
- 没进展就写没进展并说明原因，不要用"持续推进中"这类填充话。
- 风险部分不要压缩：那是上级最需要知道的。
